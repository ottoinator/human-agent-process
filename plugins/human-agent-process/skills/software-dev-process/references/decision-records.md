# Decision Records

Use decision records for choices that future maintainers should understand.

## When To Write One

Write a decision record for:

- New public claims.
- Process model changes.
- New required gates.
- License or governance changes.
- QA harness changes.
- Major repository structure changes.

Do not write one for tiny wording fixes.

## Template

```md
# Decision: <short title>

Date:
Status: proposed | accepted | superseded

## Context

What problem or decision exists?

## Decision

What did we choose?

## Alternatives

What else did we consider?

## Consequences

What becomes easier, harder, safer, or riskier?

## Evidence

What supports the decision?
```
