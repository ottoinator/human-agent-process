# Release Checklist

## Intent

- [ ] Goal and user value are clear.
- [ ] Scope and non-goals are clear.
- [ ] Owner decisions are resolved or explicitly deferred.

## Evidence

- [ ] Relevant tests or checks ran.
- [ ] Runtime or artifact proof exists when claimed.
- [ ] Security/privacy review ran when relevant.
- [ ] Documentation was updated when behavior changed.
- [ ] Claims match evidence.

## Repository

- [ ] No secrets or private data.
- [ ] No unrelated files.
- [ ] Commit message is meaningful.
- [ ] CI passes or blockers are documented.

## Validation Labels

- [ ] `automated-test`
- [ ] `reference-comparison`
- [ ] `ai-review`
- [ ] `human-validation-missing` where applicable

## Final Verdict

`release-ready | ai-ready | needs-pass | prototype-only | blocked`
