## Module: remote review link

The owner may review on a phone. Every visible or browsable result ends with a link reachable from the owner's device (private network or HTTPS), checked for a successful response. Localhost and file paths only ever appear in addition. If no route exists, report `Review link blocked: <reason>` with the next step.
